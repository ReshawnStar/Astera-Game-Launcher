# Astera 0.1.40 — More ways to play

- New installations of Gacha Nebula + use an Astera game library outside OneDrive by default. You can choose another location.
- Astera can find and link a verified existing Gacha Nebula + installation, with a manual Locate option if needed.
- Uninstall Gacha Nebula + while keeping saves, Recovery backups and personal files. Reinstall from the same Library entry.
- Fixed installation in longer folder paths, including nested Documents-style locations.

- Added Prism Launcher support for Minecraft²: find or create an instance, install the pack and launch using your existing Prism account.
- Added a CurseForge setup ZIP option for creating a new profile through its Import screen.

- Minecraft now has a shared profile selector for vanilla and detected CurseForge/Prism modpacks.
- Minecraft² restores its own artwork and icon when selected. Other profiles keep independent artwork.
- Switching profiles clears any pending Minecraft² installation plan; vanilla and unrelated modpacks do not receive Minecraft² updates.

- Fixed CurseForge profile launch when Prism also handles CurseForge links.
- Fixed diagnostic screenshots on scaled Windows displays.

- Update checks keep Astera visible and preserve maximized windows.
- CurseForge launches show progress and keep the manager in the background when possible. Open launcher is available if it needs attention.
- Long game launches show a waiting notice, optional familiar loading lines and an honest timeout status.
- Added the supplied Minecraft icon, artwork and logo for non-Minecraft² profiles.

- Game launches now use the full Astera waiting screen, with Back to library and Open launcher actions.
- Fixed mouse movement cancelling background CurseForge handling.
- Restored Gacha Nebula +’s original game icon instead of the save helper’s generic icon.

- Minecraft’s waiting screen stays up until its game window appears, rather than disappearing as soon as Java starts.
