# Estimated playtime and library organization

Astera 0.1.31 stores estimated totals in its local data directory (`playtime.json`). No account, telemetry or external playtime service is used. The preference is under Astera Settings → Library. Disabling tracking stops active sessions; existing totals are retained.

Only successful launch requests made through Astera create pending sessions. No time is charged until a running process is observed. Steam uses the app's running state or its detected installation; ordinary EXEs use their executable path; itch.io and FTL use their detected installation directory. Roblox follows the client process, with a maximum of one attributed experience. A new Roblox launch through Astera changes attribution; experience changes made inside Roblox cannot be identified. Minecraft waits for Java plus an open log in the linked profile instead of counting CurseForge itself. These are estimates, not authoritative platform statistics.

The timer polls off the UI thread every five seconds only for requested sessions, keeps working in the tray, and stops when the game closes. Totals are checkpointed every 30 seconds and on shutdown. No time is backfilled while Astera is closed. Long polling gaps are excluded so sleep/resume cannot add hours. Crashes can lose the last unsaved interval. Process restrictions, launcher handoffs and Roblox's home screen can affect accuracy. No process command lines or Minecraft authentication tokens are read.

Favorite, hidden and folder membership uses stable IDs in preferences. Folders are virtual collections and never move installed files. Hidden entries stay out of ordinary views/search; Hidden is explicit and not restored as the initial filter. Empty filters clear prior game text and artwork. This is library organization, not encryption or access control.

Startup flavor comes from `content/startup/astera_startup_lines.json`, supplied by Star/Cipher. The embedded bounded library can be replaced at build time; a bounded optional local `startup-lines.json` override is supported. Cosmetic messages stay separate from real progress and can be disabled. Animation timers pause when hidden/minimized or effects are off.

Verification: 206 grouped regression checks and 9 signed self-update/recovery checks passed for the exact 0.1.31 candidate. Tests cover observed-process time, failed launches, sleep gaps, persisted totals, Roblox attribution, collections/privacy, duplicate launch guards, startup covering, native library paint/scroll/GIF behavior and update safety. A real isolated worker validates process detection; no live Roblox experience or Minecraft gameplay session was launched for this timer. Full FTL patching is unchanged from the 0.1.30 real-file install/update/restore proof.
