# Generated Gibs for Multiverse 5.5

Astera downloads the original addon; no addon bytes are embedded in or hosted by
the Astera repository. This is not the generator executable.

- Version: 1.4.2, for Multiverse 5.5 only (including5.5.1 Data).
- Primary listing: https://www.subsetgames.com/forum/viewtopic.php?t=35332
- Author thread: https://ftlmultiverse.boards.net/thread/39/generated-gibs-mv-trc
- Generator source and documented order: https://github.com/Epirasque/FTLshipGibGenerator
- Download identity corroborated by the Multiverse translation installer's
  author-maintained catalogue:
  https://github.com/ftl-mv-translation/mvinstaller/blob/main/mvinstaller/signatures.py

- SHA256, pinned after inspection:
  `B8A616A8609B31951B4BCB71743AB9E29A8699BDFFAD12022E1029B3A91D139F`.
  This is Astera's inspected-archive pin, not an author-published digest claim.
- Archive metadata identifies Generated Gibs for Multiverse5.5 /1.4.2 and the
  same authors/thread. Contains8,022 debris PNGs and982 XML layout append patches.

Patch order: Multiverse Assets, Multiverse Data, then Generated Gibs in one ftlman
patch operation. Updates/removal rebuild from the saved vanilla base. Other
unmanaged addons are not adopted or overwritten. The enabled addon/version is
recorded in the managed state, participates in update detection and install
confirmation, and can be disabled through the per-game FTL setup dialog.

Every selected release's Data/Assets metadata and actual patched version text
are checked. Every GenGibs image is SHA256-compared to the pinned source archive;
all982 target layouts must contain the specified gib nodes/physics/positions.
Future Multiverse versions outside5.5 are rejected when this addon is enabled.
Downloads still require exact size/SHA256. No publisher credentials are required
by the original download. Loading/memory cost is disclosed in setup and notes.

These are file/patch verification claims, not proof of a visually observed ship
explosion. The live author game was not patched while it was running.
