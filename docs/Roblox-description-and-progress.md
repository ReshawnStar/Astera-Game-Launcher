# Roblox descriptions and working-indicator polish — 0.1.34

Roblox's existing universe details response now supplies the experience description. Astera verifies the returned universe identity before using it, stores bounded plain text in the library entry, and labels the panel About this experience rather than presenting a description as patch notes. Existing entries without the new metadata version refresh when opened; cached descriptions remain available offline. Missing descriptions get a local fallback rather than unrelated game or launcher text. No additional account or authentication integration was introduced.

The Working indicator previously painted its moving segment only when the 250 ms status heartbeat or a progress report invalidated it. Its indeterminate animation now owns a separate 10 ms UI timer and redraws only the small track. The track uses rounded ends and a soft accent gradient. Actual byte/file progress remains tied to reported work; the animation does not invent a completion percentage. Determinate, hidden, minimized and reduced-motion states stop the animation timer. Elapsed time/status text retain the slower heartbeat. Conflicting idle text is hidden during work and Cancel is aligned in its own footer space.

Automated checks cover cached descriptions, line breaks/control characters/size limits, correct About content, missing-description fallback, animation cadence, no idle/reduced-motion timer, actual progress values, cancellation safety and existing regressions. A separate real public Roblox lookup validates the description without joining or launching Roblox. Native description and progress screenshots were inspected. Paint cadence measures track repainting, not hardware display presentation or a universal frame-rate guarantee.
