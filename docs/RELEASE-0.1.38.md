# Astera 0.1.38

Discover now uses rounded search, responsive artwork cards with compact actions,
and right-side featured navigation. Last Light uses the supplied coming-soon
banner without altering its image. It remains unavailable for installation.

Top navigation and Discover results/detail/back navigation use an opaque loading
cover. Preparation finishes before a single completed snapshot fades and slides
up. Pending catalog/artwork requests keep the cover in place. Failed image
requests release their pending key so navigation does not stay covered forever.
Rapid navigation, resizing, reduced motion and disposal release/restage surfaces.
Game hero busy progress stays in the footer/dialog instead of a black banner strip.

The public catalog format remains backward compatible; the Last Light banner is
an embedded fallback for its existing empty artwork entry. No new signed catalog
resource unknown to older clients is published.

Validation receipts are kept locally for the exact release EXE. Source and player
release notes accompany the GitHub release. No live games or saves are modified
by the layout/transition checks.
