# Minecraft² background

`minecraft-squared.png` is the sunrise scene supplied by Star/Cipher on 2026-10-26.
It is embedded unchanged as Minecraft²'s default scene. User-selected backgrounds
take precedence. The hero adds its readability fade at runtime; character art is
a separate transparent layer.

No personal Minecraft skin, launcher profile file or rendered private character
image belongs in this directory or the repository. Those stay in the user's
local Astera `skin-cache` folder.
